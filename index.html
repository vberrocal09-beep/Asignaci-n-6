Bienvenidos al desarrollo web

En esta página conocerás los conceptos básicos necesarios para comprender cómo se crean y funcionan las páginas web.

¿Qué es una página web?

Una página web es un documento digital que puede contener texto, imágenes, videos, enlaces y otros elementos. Generalmente se visualiza mediante un navegador web.

¿Cómo funciona una página web?

Una página web funciona mediante la comunicación entre un navegador y un servidor web. Cuando un usuario ingresa una dirección o pulsa un enlace, el navegador solicita los archivos de la página al servidor, que responde enviando los recursos necesarios para mostrar su contenido.

Para construir una página web se utilizan tecnologías como HTML, que organiza el contenido; CSS, que define su apariencia; y JavaScript, que permite agregar interactividad. En las páginas dinámicas también pueden intervenir programas del servidor y bases de datos.

Tipos de páginas web

Páginas estáticas

Presentan contenido que normalmente permanece igual hasta que alguien modifica el código o los archivos.

Páginas dinámicas

Pueden mostrar contenido diferente según las acciones del usuario, los datos almacenados o la información recibida.

Diferencia entre sitio web y aplicación web

Un sitio web agrupa páginas relacionadas y puede enfocarse en presentar información. Una aplicación web permite realizar tareas interactivas, como registrar usuarios, editar datos o gestionar información.
